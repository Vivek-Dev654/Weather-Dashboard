# 🌤️ Weather Dashboard

A simple and beginner-friendly Weather Dashboard built using HTML, CSS, and JavaScript. It uses the OpenWeather API to display real-time weather information for different cities.

## 📌 Features

- 🔍 Search weather by city name
- 🌡️ Current temperature
- 💧 Humidity information
- 💨 Wind speed
- ☁️ Weather condition
- 🌍 Country information
- 📱 Responsive design
- ❌ Error message for invalid cities

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
